# Lexique

Curaté. Registre : `tous` (léger + joual), `joual`, `leger` (surtout le léger ; le joual peut s’en servir). En FR, prendre la colonne FR.

Sources semées (Québec Cité, Talk in French, The Muse), pas copiées. Daté ou douteux : voir la fin.

## Faux amis

| QC                      | FR                     | Piège                                                                                                 |
|-------------------------|------------------------|-------------------------------------------------------------------------------------------------------|
| déjeuner                | petit-déjeuner         | En France, déjeuner = midi                                                                            |
| dîner                   | déjeuner (midi)        | En France, dîner = soir                                                                               |
| souper                  | dîner (soir)           | Rare en France                                                                                        |
| bienvenue (après merci) | de rien / je t’en prie | En France, bienvenue = welcome à l’arrivée                                                            |
| blonde                  | copine / petite amie   | Pas la couleur de cheveux                                                                             |
| chum                    | copain / petit ami     | Aussi « un chum » = un ami, selon le contexte                                                         |
| échalote                | oignon vert            | En France, échalote = shallot                                                                         |
| espadrilles             | baskets                | En France, espadrilles = toile/corde                                                                  |
| facture (resto)         | addition               | Facture FR = invoice                                                                                  |
| valise (auto)           | coffre                 | Aussi l’expression *tu me prends pour une valise*                                                     |
| liquor / liqueur        | soda / limonade        | « liquor » des glossaires est une erreur ; au Québec on dit *liqueur* (boisson gazeuse) ou *breuvage* |
| cellulaire              | portable               | En France, portable = téléphone ; ordinateur portable = portable aussi                                |

## Écarter

Pas dans la voix. Daté, erroné, ou caricature de glossaire :

- `stacose` (parce que) — pas vivant à l’écrit
- `robeur` (pneu) — rare / douteux
- `liquor` pour soda — erreur ; voir *liqueur* / *breuvage*
- `J’aime le way qu’à hang` — daté, à ne pas reproduire
- chapelets de sacres en signature
- poutine / cabane à sucre / caribou comme décor identitaire
