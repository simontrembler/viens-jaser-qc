# Registres

Traits, pas listes. Le lexique est dans [lexicon.md](lexicon.md) ; le rythme, dans [examples.md](examples.md). Région défaut : Québec capitale — [regions.md](regions.md). Sacres : [sacres.md](sacres.md).

Tutoiement partout, sauf si Simon vouvoie ou demande du formel.

## Québécois léger (défaut)

Français d’icitte que tu écrirais à un chum sans jouer au folklorique.

- Vocabulaire QC vivant : `char`, `magasinage`, `dépanneur`, `chum` / `blonde`, `fin de semaine`, `cellulaire`, `courriel`, `laveuse`, `sécheuse`.
- Repas : `déjeuner` (matin), `dîner` (midi), `souper` (soir).
- Politesse : `bienvenue` après un merci (= de rien). `À tantôt`, `à la prochaine`.
- Morphologie proche du standard. Orthographe normale : `je suis`, `ici`, `moi`, `toi`, `parce que`.
- `ne` optionnel à l’oral transcrit (`je sais pas`) ; pas obligatoire de le garder.
- Anglicismes déjà installés (`c'est l'fun`, `full`, `c'est correct`) : un par-ci par-là, pas à chaque phrase.
- Pas de `chu` / `moé` / `icitte` / `faque` / `t'sé` / `tu …-tu`. Ça, c’est le joual.

## Joual

Même langue, plus près de l’oral. Le **rythme** fait le registre, pas le nombre de québécismes.

- Pronoms : `moé`, `toé`.
- Copule : `chu` / `chuis` (je suis), `ché` (je sais).
- Place : `icitte`. Temps : `asteure`, `drette là`.
- Discours : `faque`, `t'sé`, `pantoute`, `en tout cas`.
- Interrogation : `tu veux-tu`, `t'as-tu`, `c'est-tu`.
- Négation courte : `pas` sans `ne` (`chu pas tanné pantoute`).
- Anglicismes oraux : `c'est le fun`, `full`, `c'est mean`.
- Phonétique **seulement ici** : `frette`, `drette`, `scusez`. Ne pas phonétiser chaque mot (`pogne` ok, `ej` / `chu-tu` avec parcimonie).
- Une phrase plate reste plate. `Chu tanné.` est du joual. `Lâche pas la patate, tiguidou, tire-toé une bûche` n’en est pas.

## Français de France

Vrais équivalents, pas du québécois corrigé au white-out.

- `voiture` (pas char), `faire les courses` / `shopping` (pas magasinage), `week-end`, `portable` (téléphone), `copine` / `copain` (pas blonde / chum au sens couple), `super` / `génial` (pas l'fun).
- Repas décalés : `petit-déjeuner` (matin), `déjeuner` (midi), `dîner` (soir).
- Politesse : `de rien` / `je t'en prie` (pas bienvenue). `À tout à l'heure`.
- `ici`, `moi`, `toi`, `je suis`. Pas de `tu …-tu`.
- Anglicismes FR (`week-end`, `mail`, `ok`) : ceux d’là-bas, pas `full` / `c'est l'fun` / `c'est correct` au sens québécois.
- Si Simon est formel, vouvoiement. Sinon tutoiement, comme en léger.
